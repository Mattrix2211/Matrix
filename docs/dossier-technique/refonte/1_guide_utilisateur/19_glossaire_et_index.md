# Glossaire minimal et index des termes

<div class="ligne-public"><b>Public :</b> tous · <b>Ce que vous y trouverez :</b> les mots du guide, leur sens dans Matrix et la page où les retrouver · <b>Glossaire complet :</b> [[RF:30_glossaire]]</div>

## Glossaire minimal

| Terme | Sens dans Matrix |
|---|---|
| **Rôle** | Profil d'accès dans Matrix (équipier, chef de section, chef de secteur, chef de service…). Ce n'est ni un grade ni une fonction |
| **Fonction** | Ce que la personne exerce réellement : chef de liste, BSC, COMAEQ… |
| **Périmètre** | Ce sur quoi vous agissez : votre section, votre secteur, votre service, votre bâtiment |
| **Occurrence (échéance)** | Une maintenance à réaliser à une date donnée |
| **Compte rendu** | Le résultat d'une maintenance ou d'une tâche, rédigé par l'exécutant |
| **En validation** | État d'une maintenance dont le contrôle est non conforme, en attente d'une correction du compte rendu par un chef de secteur ou plus |
| **Anomalie** | Ce que vous avez vu d'anormal, avec ou sans équipement identifié |
| **Ticket correctif** | La réparation d'un équipement précis, de son diagnostic à sa remise en service |
| **Tour de service** | Un quart à la mer ou un service à quai |
| **Chef de liste** | Marin désigné pour préparer les listes de quarts ou de services d'un périmètre |
| **BSC** | Rédacteur de la feuille de service, désigné par le COMAEQ |
| **COMAEQ, COMOPS, COMANAV, COMAVIA** | Commandants adjoints du bâtiment, chacun pour sa fonction |
| **RETEX** | Retour d'expérience : un cas significatif devenu enseignement validé |
| **Accusé de réception** | Votre confirmation d'avoir lu une annonce |
| **Instance de démonstration** | Copie isolée de Matrix avec des données fictives, utilisée pour les captures |
