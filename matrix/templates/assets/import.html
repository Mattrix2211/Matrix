Importer du matériel depuis un fichier Excel

Retour à la liste

Cette page permet de créer plusieurs matériels d'un coup (extincteurs, EPI...) à partir d'un fichier Excel, plutôt que de les saisir un par un.

  1. Téléchargez le modèle ci-dessous et remplissez une ligne par matériel.
  2. Importez le fichier rempli : les matériels sont créés directement.
  3. Si certaines lignes contiennent une erreur, elles sont listées ci-dessous avec leur numéro — corrigez-les dans le fichier puis réimportez uniquement ces lignes (attention : réimporter tout le fichier crée de nouveaux matériels en double, le numéro de série n'étant pas utilisé comme identifiant unique).
