Balise : {% load composants %}{% grille id="cr-extincteurs" libelle="Compte rendu de contrôle" colonnes=colonnes lignes=lignes %}...{% fin_grille %} Paramètres : id : identifiant (obligatoire si la page porte plusieurs grilles) libelle : nom accessible de la grille (obligatoire) colonnes : liste de dictionnaires {nom, libelle, type, choix, placeholder} type : « texte » (défaut), « nombre », « date » (saisie JJ/MM/AAAA, à interpréter par la vue) ou « conformite » (liste de choix) ; choix : liste de {valeur, libelle} pour « conformite » (défaut : conforme / non_conforme) lignes : liste de dictionnaires {cle, libelle, valeurs, erreurs} valeurs : {nom_de_colonne: valeur} ; erreurs : {nom_de_colonne: message} (erreur affichée DANS la cellule, ligne par ligne) colonne « nombre » : min et max facultatifs (plage attendue) ; une valeur hors plage s'affiche en rouge, sans bloquer libelle_ligne : en-tête de la première colonne (« Élément » par défaut) lecture_seule : vrai = consultation seule (équipage à terre) : aucune saisie, aucun bouton libelle_final : texte du bouton principal (« Enregistrer » par défaut) brouillon : clé stable « formulaire:objet » (ex. « cr-extincteurs:12 ») : active l'enregistrement automatique d'un brouillon côté serveur (static/js/brouillon.js, docs/UX.md §5.4) : enregistrement 2 s après la dernière frappe, « Brouillon enregistré à HH:MM », « Reprendre le brouillon du … / Abandonner » à la réouverture, suppression après l'envoi réussi. Un seul brouillon par utilisateur et par clé ; mots de passe jamais conservés. Seuls les champs DE LA GRILLE (et de « contenu ») sont conservés. libelle_brouillon : texte affiché dans « Mes brouillons à reprendre » (libellé de la grille par défaut) classes : classes CSS supplémentaires contenu : HTML libre placé sous la grille (champs cachés, observations), fourni par le bloc Champs envoyés : « __ » (ex. « 12__etat »), une valeur vide si non saisi. Clavier : flèches et Tab / Maj+Tab = cellule voisine, Entrée = cellule du dessous (n'envoie jamais le formulaire), Échap = annule la saisie en cours dans la cellule, Ctrl+D = recopie la cellule active vers le bas (même action que le bouton « Recopier vers le bas »), Ctrl+V = collage multi-cellules depuis Excel. « Tout conforme » : ne touche que les cellules de conformité VIDES ; les « non conforme » et « non applicable » déjà saisis sont conservés. Cellule modifiée = bordure gauche épaisse, comptée dans le pied. La barre d'outils est masquée tant que le JS ne l'a pas affichée.
